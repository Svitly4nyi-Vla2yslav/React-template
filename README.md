# React Template

Базовий React-шаблон на TypeScript і Vite з маршрутизацією, локалізацією та готовими компонентами навігації, контактної форми й правових сторінок.

## Локальний запуск

1. Встановіть залежності:

   ```bash
   npm install
   ```

2. Запустіть Vite у режимі розробки:

   ```bash
   npm run dev
   ```

3. Для перевірки production-збірки виконайте:

   ```bash
   npm run build
   npm run preview
   ```

Команда `build` спочатку запускає TypeScript, а потім створює Vite-збірку. Окремий `lint` перевіряє файли `.ts` і `.tsx` без дозволених попереджень.

## Структура й локалізація

- `src/components` — повторно використовувані блоки інтерфейсу;
- `src/pages` — сторінки маршрутів;
- `src/utils` — допоміжні функції прокручування та кешування;
- `public/locales/{lng}/translation.json` — словники для `en`, `ru`, `es` і `uk`.

Конфігурація `src/i18n.ts` спочатку читає мову з `localStorage`, потім — налаштування браузера, а резервною локаллю є англійська. `LanguageProvider` надає вибрану мову дереву React.

SVG можна імпортувати як React-компоненти через `vite-plugin-svgr`. Глобальні стилі й маршрутизатор підключаються в `src/main.tsx`.
